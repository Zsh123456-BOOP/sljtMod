# sljtMod

这是一个给《杀戮尖塔 2》做的游戏内统计 + 路线分析 + 接口 + 修改器工具包。

如果你只是想直接安装，不想研究源码：

- 直接下载根目录里的 `Sts2McpInstaller_latest.zip`
- 解压后双击 `Install-Sts2Mcp.bat`
- 进游戏按 `F8` 显示/隐藏面板，按 `F7` 重置位置

## 这玩意能干什么

### 1. 游戏内 Overlay 面板

- 战斗面板：当前战斗贡献榜、状态、日志、路线建议
- 总计面板：整局统计、单机/联机拆分
- 路线面板：可视化路线候选、地图高亮、类型统计
- 修改器面板：改血量、改金币、加遗物、加卡、升级牌库卡牌

### 2. 贡献统计，不只看木桩 DPS

有些人打牌时只看一个数字，仿佛世界上只剩下 `DPS`。

这个 Mod 专门给这种“DPS 战士”补一刀现实教育：

- `直伤 nDPS`：你自己直接打了多少
- `辅助增伤 Support Damage`：你给队友创造了多少额外伤害
- `减伤 Mitigation`：你让队友少挨了多少打
- `团队护盾 Team Block`：你给团队抬了多少盾
- `状态分 Status Score`：不是你没打伤害，你只是把队友养肥了
- `综合贡献分 Contribution Score`：防止某些人看到自己 DPA 高了就宣布 MVP

简单说：

- 如果你只会喊“我 DPS 第一”
- 面板会冷静地告诉你：不，你可能只是“伤害高，但贡献一般”


### 3. 修改器

支持：

- 直接给当前局添加遗物
- 直接设置当前生命值
- 直接设置金币
- 直接往当前牌库里塞卡
- 读取当前牌库并升级指定卡牌

但要说清楚：

- 修改器是为了体验爽局，不是为了让游戏变得更有设计感
- 用多了以后，尖塔不一定爬得更高，但乐趣一般会掉得更快
- 建议把它当测试工具、整活工具，不要当成“标准玩法”

## 一键安装

### 给普通玩家

1. 下载根目录里的 `Sts2McpInstaller_latest.zip`
2. 解压
3. 双击 `Install-Sts2Mcp.bat`
4. 如果安装器提示游戏正在运行，先关游戏，或者让安装器自动关闭
5. 启动游戏

### 卸载

1. 打开你解压出来的安装包目录
2. 双击 `Uninstall-Sts2Mcp.bat`

## 注意事项

### 1. 可能掉存档

这个必须写在前面。

因为它会：

- 注入运行时
- 监听战斗、地图、牌库、遗物等状态
- 提供修改器能力

所以它有概率导致：

- 当前局异常
- 存档损坏
- 联机不同步
- 版本更新后直接失效

建议：

- 先备份存档
- 先在无所谓的测试档上试
- 联机时谨慎使用，尤其不要开着修改器乱改

### 2. 联机风险

这不是联机官方支持的功能。

如果你在联机里：

- 开修改器
- 强行改血量金币
- 给自己塞卡塞遗物

那结果可能包括但不限于：

- 房间不同步
- 队友问号
- 游戏爆炸
- 你成为“那个 Mod 哥”

### 3. 修改器不是正经平衡内容

如果你只是想体验：

- “我这把想当神”
- “我这把想带 20 个遗物”
- “我这把想让牌库膨胀成垃圾场”

那它很好用。

如果你想要的是正常游戏体验，那建议少用。
